# ORIGINS X

Juego web inspirado en la dinámica de PokéSurvivor y adaptado a sistemas, animaciones y contenido de Legend of Mir 3.

## Regla de desarrollo

- No copiar repositorios completos dentro del juego.
- PokéSurvivor se usa como referencia de gameplay y flujo.
- Zircon se usa como referencia técnica para movimiento, animaciones, mapas, combate, magias, monstruos y red.
- Solo se incorpora cada sistema cuando lo necesitamos.
- Cada sistema debe quedar funcional antes de pasar al siguiente.
- Los assets se organizan por personaje, monstruo, magia y mapa para poder sustituirlos sin tocar el motor.

## Referencias fijadas

- PokéSurvivor: `JPTER78/pokesurvivor` — referencia base `b297089`.
- Zircon: `Suprcode/Zircon` — referencia técnica.

## Primer objetivo

Conseguir un personaje MIR3 en pantalla con movimiento y animación correctos en 8 direcciones. Después se incorporarán mapa, monstruos, combate y magias, en ese orden.
