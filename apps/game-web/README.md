# ORIGINS Web Runtime

This directory is reserved for the first integrated playable ORIGINS client.

It must combine, without rewriting the source/reference systems:
- grey Zuma room runtime;
- Crystal player locomotion;
- collision/floor transitions;
- Zircon desktop GameInter and first clickable windows.

Implementation instructions live in `docs/CURSOR_IMPLEMENTATION_PLAN.md`.

Do not place extraction tools or upstream source libraries in this directory.
