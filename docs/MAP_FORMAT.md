# MAP Format

Aquí documentaremos el formato `.map` utilizado por los mapas de Zircon que vayamos incorporando.

El objetivo no es aproximar el mapa sino poder resolver, para cada celda y capa:

- coordenada;
- librería;
- image/tile ID;
- offsets;
- orden de dibujo;
- flags de terreno/colisión cuando estén disponibles.

Cuando se confirme una variante concreta del formato se documentará con ejemplos verificables.
