# Library Index

Este documento será el índice humano de las librerías Zircon cargadas en el repositorio.

El índice automatizado vive en `ZIRCON_ASSETS/manifests/library_index.json`.

Para cada librería registraremos:

- nombre original;
- clave estable;
- tipo ZL;
- número de slots;
- imágenes presentes;
- finalidad conocida;
- relación con mapas;
- estado de extracción.
